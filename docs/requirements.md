# 纯帧 - 需求分析文档

> 纯粹观影，只留帧影

## 1. 产品概述

### 1.1 产品定位

**纯帧** 是一款文艺极简的本地视频播放器，核心差异化：
- 无广告打扰
- 纯黑沉浸主题
- 边下边播能力

### 1.2 目标用户

| 用户类型 | 特征 | 使用场景 |
|---------|------|---------|
| 影视爱好者 | 追求高品质观影体验 | 本地视频收藏、下载观看 |
| 隐私敏感者 | 不愿意被推荐算法追踪 | 纯净播放，无数据分析 |
| 设计师/创作者 | 美学敏感，讨厌臃肿 UI | 极简界面，高级感体验 |
| 磁力资源用户 | 常用 magnet 链接下载 | 一站式下载+播放 |

### 1.3 核心价值

- **纯粹性**：无广告、无推荐、无数据收集
- **极简性**：界面克制，只保留必要功能
- **实用性**：边下边播，提升观看效率

## 2. 功能需求

### 2.1 本地视频播放（核心）

#### 2.1.1 视频扫描与管理

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 自动扫描 | 启动时扫描常见视频目录（Movies、Downloads、DCIM） | P0 |
| 文件夹浏览 | 按文件夹结构展示视频列表 | P0 |
| 手动添加目录 | 用户可添加自定义视频目录 | P1 |
| 视频缩略图 | 自动生成/加载视频封面 | P2 |
| 最近播放 | 记录最近播放的视频，快速访问 | P1 |
| 收藏功能 | 标记喜欢的视频 | P2 |

#### 2.1.2 播放控制

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 基础控制 | 播放/暂停、进度拖动、全屏切换 | P0 |
| 倍速播放 | 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x, 3x | P0 |
| 音量/亮度调节 | 手势滑动调节（左侧亮度，右侧音量） | P0 |
| 进度记忆 | 自动记录播放进度，下次继续 | P0 |
| 硬解/软解切换 | 针对特殊格式视频 | P1 |
| 后台播放 | 退到后台时继续播放音频 | P1 |
| 播放模式 | 单次播放、循环播放、列表连续播放 | P2 |

#### 2.1.3 支持格式

| 格式类型 | 格式列表 | 备注 |
|---------|---------|-----|
| 常见格式 | mp4, mkv, mov, avi | 优先支持 |
| 流媒体格式 | ts, flv, m3u8 | 边下边播场景 |
| 特殊格式 | webm, rmvb, wmv | 软解支持 |

### 2.2 磁链下载（核心）

#### 2.2.1 磁链输入

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| magnet 链接粘贴 | 从剪贴板识别 magnet: 链接 | P0 |
| .torrent 文件上传 | 从文件选择器打开 torrent 文件 | P1 |
| 链接分享接收 | 从其他应用分享链接到纯帧 | P2 |

#### 2.2.2 下载管理

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 多任务下载 | 支持同时下载多个任务 | P0 |
| 暂停/继续 | 随时暂停和恢复下载 | P0 |
| 任务列表 | 显示下载中、已完成任务 | P0 |
| 进度显示 | 实时显示下载进度、速度 | P0 |
| 文件选择 | 选择下载 torrent 中的部分文件 | P1 |
| 下载路径设置 | 自定义下载保存目录 | P1 |
| 后台下载 | 退到后台继续下载 | P1 |
| 下载完成通知 | 任务完成后推送通知 | P2 |

### 2.3 边下边播（核心亮点）

#### 2.3.1 播放触发条件

- 下载进度 >= 10%（可配置阈值）
- 已下载片段连续（至少 5 分钟内容）

#### 2.3.2 播放约束

| 约束 | 描述 |
|-----|------|
| 进度限制 | 仅能在已下载区域内拖动进度条 |
| 界面提示 | 显示「已缓存 XX%」进度条 |
| 播放优先 | 播放时不影响下载速度（独立线程） |
| 自动续播 | 下载足够时自动提示可播放 |

## 4. 非功能需求

### 4.1 性能要求

| 维度 | 目标 |
|-----|------|
| 启动时间 | < 2 秒 |
| 视频加载 | < 1 秒（本地文件） |
| 播放流畅度 | 60fps，无卡顿 |
| 下载速度 | 接近带宽上限 |
| 内存占用 | < 150MB（播放时） |

### 4.2 安全要求

| 维度 | 要求 |
|-----|------|
| 数据安全 | 不上传用户数据，本地存储 |
| 网络安全 | 仅用于磁链下载，无其他网络请求 |
| 权限最小化 | 仅申请必要权限 |

### 4.3 兼容性要求

| 维度 | 范围 |
|-----|------|
| Android 版本 | 8.0 (API 26) ~ 14 (API 34) |
| 屏幕尺寸 | 支持手机、平板 |
| 横竖屏 | 全屏播放时自动横屏 |

## 5. 用户故事

### 5.1 本地播放场景

> "我有大量本地电影收藏，想用一个简洁的播放器观看"

1. 用户打开纯帧
2. 应用自动扫描本地视频
3. 显示视频列表（按文件夹或最近播放）
4. 点击视频进入播放
5. 播放界面极简，只显示必要控制
6. 触手势调节音量、亮度、进度
7. 退出后自动记忆进度

### 5.2 磁链下载场景

> "朋友分享了一个 magnet 链接，我想在手机上下载并观看"

1. 用户复制 magnet 链接
2. 打开纯帧，切换到下载页
3. 应用自动识别剪贴板中的 magnet 链接
4. 显示下载任务详情（文件列表、大小）
5. 开始下载
6. 下载过程中可查看进度
7. 下载完成后直接播放

### 5.3 边下边播场景

> "我想先看一部分，不想等全部下载完"

1. 用户粘贴 magnet 链接开始下载
2. 下载进度达到 10% 时，界面提示「可播放」
3. 用户点击播放按钮
4. 进入播放界面，显示「已缓存 XX%」
5. 用户只能在已缓存区域内拖动进度
6. 播放流畅，不影响下载速度
7. 下载完成后，自动解除进度限制
